# Week 3 Data Processing Notebook

This repository contains the completed notebook for Week 3, which generates a student dataset, validates records, calculates grades, and summarizes district performance.

## Project overview

The notebook performs the following tasks:
- creates a CSV file named `week3_students.csv`
- classifies score ranges into grade bands
- validates student records using score and attendance rules
- calculates pass rates and top-performing students
- reads the CSV and filters invalid entries
- summarizes averages by district
- writes a final text report file

## Key results

From the notebook execution:
- valid records: 37
- invalid records: 3
- average valid score: 70.5
- pass rate: 90.0%
- top student: Hakizimana Kayitesi with score 97 and grade A
- highest average district: Nyanza with 82.8

## Files

- `Week3_Douglas.ipynb` — main notebook with all exercises and outputs
- `week3_students.csv` — generated student dataset
- `week3_report.txt` — final summary report generated by the notebook

## How to run

Open the notebook in VS Code and select a Python Jupyter kernel, then run all cells.

If the notebook kernel is not available, install `ipykernel` in the selected Python environment and register the kernel before running.
